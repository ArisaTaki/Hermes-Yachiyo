Phase 3 direction / desktop-first agent OS

一张月光下的本地 Agent 工作台：安装、配置、初始化、陪伴使用。

把 Hermes-Yachiyo 定位为 macOS 桌面上的 Hermes Agent 控制室： 先完成运行时安装、模型供应商验证和本地工作区初始化，再进入聊天窗口、 气泡模式、Live2D 模式、主动关照、TTS / GPT-SoVITS 资源、工具、 诊断、备份恢复与卸载预览。

1. 产品定位

macOS 本地优先的个人 Agent 工作台，不是 SaaS 落地页，也不是通用聊天机器人。Yachiyo 负责桌面外壳、资源、关照、设置和安全维护。

2. 主要用户流

  • 安装 Hermes Agent
  • 配置模型供应商与默认模型
  • 初始化本地工作区
  • 首条消息后切换气泡或 Live2D

3. 信息架构

安装、供应商、工作区、会话、桌面模式、关照与语音、工具、诊断、维护。

4. 组件方向

  • 本机状态胶囊
  • 安装步骤卡
  • 供应商字段组
  • 资源导入行
  • 诊断发现项

5. 视觉 Token

月黑背景、半透明层级面板、Hermes 青绿表示可用 / 本机，紫色只用于当前选择和关键操作。

6. 优先重设计

首次启动运行手册

02 Hermes Agent 一键安装，展示终端输出、失败原因与重试入口。
03 模型供应商 供应商、模型、Base URL、API Key 和连接测试。
04 本地工作区 初始化数据、附件、日志、资源和备份目录。
05 首条消息 打开聊天，再同步到气泡或 Live2D 模式。
